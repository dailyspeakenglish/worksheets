8Used to · be used to · get used to new! grammar4 points

Maltz's patients needed time to get used to their new face. Three similar phrases – three different meanings!

used to + verba past habit that has stopped
"I used to run every day."
be used to + -ing / nounit's normal for you now
"I'm used to getting up early."
get used to + -ing / nounit's becoming normal
"You'll get used to it!"
1. When Lucy started, she write a whole page. Now she writes three lines.
2. After an operation, the patients needed time to their new face.
3. I'm a morning person, so I waking up early. It's easy for me.
4. Running is hard at first, but your body will it.
Jack's tip: After be used to and get used to, the verb needs -ing: "I'm used to waking up early" – not "I'm used to wake up". It's one of the most common learner mistakes!
